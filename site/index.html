COAL converts a protein multiple sequence alignment and the matching coding DNA into a codon alignment.

It is a drop-in replacement for PAL2NAL. It reads the same input and takes PAL2NAL's options, and it writes the same output as PAL2NAL v14 in all four of its formats (FASTA, CLUSTAL, PAML and codon), apart from a short list of documented differences. When a gene does not fit, it tells you which one and why.

Version 0.3.0. MIT licence. Python 3.10 or newer on any system, or a Windows app that needs nothing else installed.

Download the Windows installer

COAL-Setup-windows-x64.exe, for 64-bit Windows 10 and 11. It installs for your user account only and needs no administrator rights. It is not code-signed yet, so Windows asks you to confirm before it runs.

If Smart App Control blocks it, install with pip.

Install with pip

Needs Python 3.10 or newer. Install into a virtual environment, as in the macOS and Linux steps. COAL is not on PyPI, so a plain pip install coal gets you a different package.

python3 -m pip install "coal[gui] @ https://github.com/plumat-coal/COAL/releases/latest/download/coal_src.tar.gz"

Example

The clean example in the repository has eight genes of 140 to 144 codons (plus a stop codon), aligned in 150 columns. The protein alignment has gaps, the DNA has none.

$ coal examples/clean/protein.aln.fasta examples/clean/dna.fasta -o codon.aln.fasta
$ echo $?
0
$ head -3 codon.aln.fasta
>gene01
ATG---GCGAGG---CCTTCCACTACTACCGTGAATATGTGGGGCTCGACACCAGTTTGG
AATGGAGGG---AAAATG---TGGTTTGCTATGGGCGCCGTTGATAATATGCCTACCATG

For pipelines: COAL takes PAL2NAL's options (coal pep.aln nuc.fasta -codontable 2 -o out.fasta), and the package installs a pal2nal command that accepts PAL2NAL's command line unchanged. One difference: with -nogap, COAL removes the stop codons of the genetic code you chose. Large inputs are split across processes automatically (-j sets the limit).

When a gene doesn't fit

The mito example has 24 vertebrate mitochondrial genes. Mitochondria read TGA as tryptophan and ATA as methionine, so with the default standard code COAL writes the alignment but warns about every codon that disagrees with its residue:

$ coal examples/mito/protein.aln.fasta examples/mito/dna.fasta -o codon.aln.fasta
coal: warning: Homo_COX1 pepAlnPos 1: M does not correspond to ATA
coal: warning: Homo_COX1 pepAlnPos 7: M does not correspond to ATA
coal: warning: Homo_COX1 pepAlnPos 36: W does not correspond to TGA
(176 more warnings, 179 in all)
$ coal examples/mito/protein.aln.fasta examples/mito/dna.fasta -codontable 2 -o codon.aln.fasta
$

The desktop app runs the same engine and reads those 179 lines for you. For the same run it shows one sentence per gene and a suggestion:

Homo_COX1: 7 codons do not match their amino acid (first at column 1): the protein says M but the DNA has ATA. Kept in the alignment; check the genetic code.

Under genetic code 2 (Vertebrate mitochondrial), all 24 sequences match their protein; under code 1, none do. Codes 5 and 13 fit these sequences too: choose the code of the organism and organelle the genes come from. Re-run with code 2?

A frameshift inside a gene is usually an error, not a warning. (A base missing near the end of a gene can still let the gene fit, with a few mismatch warnings; the app then says the run of mismatches looks like a frameshift.) In the one_broken_gene example one base is missing from one of 20 genes:

$ coal examples/one_broken_gene/protein.aln.fasta examples/one_broken_gene/dna.fasta -o codon.aln.fasta
coal: error: OG0001_sp14: protein and DNA are inconsistent (no match found)
$ echo $?
1

PAL2NAL reports an inconsistency here too, but exits with status 0, so a pipeline carries on. COAL stops. The app goes one step further and finds the column:

OG0001_sp14: Frameshift at column 102: one base is missing in the DNA, so from here on the codons are read out of step. Check the DNA near there (a sequencing or assembly error?).

Compared with PAL2NAL

PAL2NAL (Suyama, Torrents and Bork, 2006) has been the usual tool for this conversion since it was published. COAL is an independent reimplementation in Python. PAL2NAL is licensed under the GPL-2.0 and COAL under MIT. COAL contains none of PAL2NAL's code: we ran PAL2NAL version 14 as a separate program, only to compare outputs.

COAL's output is identical to PAL2NAL v14's except for a short list of documented, deliberate differences: newer NCBI genetic-code tables (codes 3, 10, 11 and 13), -nogap removing the chosen code's stop codons, the chosen code's start codons for the first Met, and inputs where PAL2NAL v14 writes malformed output or fails.

The test suite compares COAL with stored PAL2NAL v14 output on 38 input cases with every option combination in all four output formats, 279 checks in all. Standard output is byte-identical in 232 checks (in 4 of them the warnings differ deliberately); in 24 both tools fail; and 23 checks are deliberate output or exit-status differences. Some of them:

  • An invalid character in the protein alignment is an error. PAL2NAL silently drops a codon.
  • . is read as a gap. In PAL2NAL it misaligns the output row.
  • Genetic codes follow the current NCBI tables. In code 10, TGA is cysteine; PAL2NAL treats it as a stop.
  • With -nogap, COAL removes the stop codons of the genetic code you chose. PAL2NAL always uses the standard code's stops, so in mitochondrial data it deletes real tryptophan (TGA) columns.
  • Probably-wrong data, such as unrelated DNA or a gene where most codons do not match, gets a notice. With --strict it is an error.
  • Any error gives a non-zero exit status. PAL2NAL always exits with 0.

The full list is in the README and tests/README.md.

Speed and memory

Measured on one Windows 11 laptop (Intel 64-bit CPU, Family 6 Model 183; Python 3.13.9; Strawberry Perl 5.42.3) with synthetic data. Each time is the median of 3 runs of the whole command, start-up included.

COAL and PAL2NAL v14, wall-clock time
Genes × codonsPAL2NALCOALPAL2NAL ÷ COAL
10 × 5000.051 s0.061 s0.8×
1,000 × 5002.39 s0.139 s17.3×
10,000 × 50024.7 s0.864 s28.6×
100 × 10,00024.5 s0.207 s118.6×

On tiny inputs both tools take about 0.05 s, nearly all of it start-up, and COAL is slightly slower. PAL2NAL's time grows faster than gene length; COAL's grows in proportion to the input.

Half a million genes of 500 codons (974 MB of FASTA) took 9.8 s with 4 processes and 25.2 s with one. The one-process run peaked at 131 MB of memory. We did not run PAL2NAL at that size.

Synthetic data, one machine, 3 repeats. Raw data and the command to reproduce: README, benchmark results.

Limitations

  • Gblocks-format input and PAL2NAL's -html web-server output are not supported. The coal command writes FASTA unless you ask for another format; the pal2nal drop-in defaults to CLUSTAL, as PAL2NAL does.
  • The Windows installer is not code-signed. SmartScreen asks you to confirm, and Smart App Control blocks it outright.
  • Not on PyPI. Install from the release with the commands on this page.
  • More than 4 processes do not help yet: one main process reads and writes everything.
  • No DOI yet (see Cite).

Install

Steps for Windows, macOS and Linux. To update, run the same install again; it fetches the newest release.

Windows (this computer)

  1. Download COAL-Setup-windows-x64.exe.
  2. Edge may say the file isn't commonly downloaded. Click … next to the message, then Keep, Show more and Keep anyway.
  3. Open the file. Windows shows Windows protected your PC. Click More info, check that the app is COAL-Setup-windows-x64.exe and the publisher is Unknown publisher, then click Run anyway.

    Windows cannot name the publisher because COAL has no code-signing certificate yet. You can check the file's checksum first.

  4. Choose whether you want a desktop shortcut and an Open with entry for .fasta and .aln files. Both are optional, and COAL never makes itself the default program. Click Install. COAL goes into %LOCALAPPDATA%\Programs\COAL.
  5. Start COAL from the Start menu. The first start takes about ten seconds. Drop your protein alignment and DNA onto the window, or click Try an example.

If Smart App Control blocked COAL

Smart App Control on Windows 11 blocks unsigned apps. It has no Run anyway button and no way to allow a single app. You can switch it off, but on some Windows versions it can then only be switched back on by resetting or reinstalling Windows. Leave it on and install with pip instead. In PowerShell, with Python 3.10 or newer from python.org:

py -m venv $HOME\coal-env & $HOME\coal-env\Scripts\python -m pip install "coal[gui] @ https://github.com/plumat-coal/COAL/releases/latest/download/coal_src.tar.gz" & $HOME\coal-env\Scripts\python -m coal_app

The last line starts the app. Open http://127.0.0.1:7860 in your browser.

To run COAL without installing, unzip COAL-windows-x64.zip and run COAL\COAL.exe. Windows asks for the same confirmation. On a managed university or company laptop, IT policy may block both. COAL only listens on this computer (127.0.0.1).

macOS (this computer)

  1. In Terminal, check python3 --version. You need 3.10 or newer; if not, install the current Python from python.org.
  2. Make a virtual environment for COAL:
    python3 -m venv ~/coal-env
  3. Install COAL and its app into it:
    ~/coal-env/bin/python -m pip install "coal[gui] @ https://github.com/plumat-coal/COAL/releases/latest/download/coal_src.tar.gz"
  4. Start the app and open http://127.0.0.1:7860 in your browser. Ctrl+C in Terminal stops it.
    ~/coal-env/bin/coal-gui

Linux (this computer)

  1. Check python3 --version (3.10 or newer). On Debian and Ubuntu you may need sudo apt install python3-venv as well.
  2. Recent Debian, Ubuntu and Fedora refuse pip install outside a virtual environment, so make one and install COAL into it:
    python3 -m venv ~/coal-env ~/coal-env/bin/python -m pip install "coal[gui] @ https://github.com/plumat-coal/COAL/releases/latest/download/coal_src.tar.gz"
  3. Start the app with ~/coal-env/bin/coal-gui and open http://127.0.0.1:7860. On a server, use the command line.

Command line only

The pip install also puts coal and pal2nal in ~/coal-env/bin ($HOME\coal-env\Scripts on Windows). If you only need the command line, write coal instead of coal[gui] in the install command and nothing else is installed.

coal protein.aln.fasta dna.fasta -o codon.aln.fasta
coal protein.aln.fasta dna.fasta -codontable 2 -nogap -o codon.aln.fasta
coal --help

Check a download

Download SHA256SUMS.txt into the same folder as the file and compare.

Windows (PowerShell)

Get-FileHash .\COAL-Setup-windows-x64.exe -Algorithm SHA256

The hash must equal the one on the COAL-Setup-windows-x64.exe line of SHA256SUMS.txt. Case does not matter.

Linux

sha256sum -c --ignore-missing SHA256SUMS.txt

Every file you downloaded must say OK.

macOS

shasum -a 256 coal_src.tar.gz

Compare with the coal_src.tar.gz line of SHA256SUMS.txt.
