Put the DNA back under your protein alignment.

COAL takes a protein alignment and the DNA of the same genes and writes the codon alignment you need for dN/dS and DNA trees. When a gene doesn't fit, it tells you which one and why, in plain words. Free, open source, and it runs on your own computer.

Download for Windows

Installer for Windows 10 and 11, 64-bit. Installs for you only, no administrator rights. It isn't code-signed yet, so Windows will ask you to confirm.

Windows blocks it with Smart App Control? Install with pip instead.

Install with pip

For macOS and Linux (and Windows). Needs Python 3.10 or newer; run it inside a virtual environment, as in the macOS and Linux steps.

python3 -m pip install "coal[gui] @ https://github.com/plumat-coal/COAL/releases/latest/download/coal_src.tar.gz"

Install

Jump to Windows, macOS or Linux.

Windows (your system)

  1. Download COAL-Setup-windows-x64.exe.
  2. Edge may say the file isn't commonly downloaded. Click … next to the message, then Keep, then Show more and Keep anyway.
  3. Open the file. Windows shows a blue box, Windows protected your PC. Click More info. Check that it names COAL-Setup-windows-x64.exe and says Publisher: Unknown publisher, then click Run anyway.

    Why: COAL doesn't have a code-signing certificate yet, so Windows can't name the publisher. You can check the download against the published checksum first.

  4. Choose whether you want a desktop shortcut and an Open with entry for .fasta and .aln files (both optional; COAL never becomes your default program). Click Install. COAL installs in your own user folder, %LOCALAPPDATA%\Programs\COAL.
  5. Start COAL from the Start menu. The first start can take ten seconds or so. Drop your protein alignment and DNA onto the window, or click Try an example.

If Smart App Control blocked COAL

On Windows 11, Smart App Control blocks apps that aren't signed, with no Run anyway button and no way to allow just one app. Turning it off for COAL isn't a good trade (on many Windows versions it can't be turned back on without reinstalling Windows). Install with pip instead, in PowerShell, with Python 3.10 or newer from python.org:

py -m venv $HOME\coal-env & $HOME\coal-env\Scripts\python -m pip install "coal[gui] @ https://github.com/plumat-coal/COAL/releases/latest/download/coal_src.tar.gz" & $HOME\coal-env\Scripts\python -m coal_app

The last line starts the app; open http://127.0.0.1:7860 in your browser.

Portable instead of installed: unzip COAL-windows-x64.zip and run COAL\COAL.exe (Windows shows the same confirmation). On a university or company laptop, IT policy may block either; COAL only listens on this computer (127.0.0.1).

macOS (your system)

  1. Open Terminal and check your Python: python3 --version. You need 3.10 or newer. If it's older or missing, install the current Python from python.org.
  2. Make a separate environment for COAL (so it can't clash with other software):
    python3 -m venv ~/coal-env
  3. Install COAL with its app:
    ~/coal-env/bin/python -m pip install "coal[gui] @ https://github.com/plumat-coal/COAL/releases/latest/download/coal_src.tar.gz"
  4. Start the app, then open http://127.0.0.1:7860 in your browser. Stop it with Ctrl+C in Terminal.
    ~/coal-env/bin/coal-gui

Linux (your system)

  1. Check your Python: python3 --version (3.10 or newer). On Debian and Ubuntu you may also need sudo apt install python3-venv.
  2. Make a separate environment and install COAL into it (recent Debian, Ubuntu and Fedora refuse pip install outside one):
    python3 -m venv ~/coal-env ~/coal-env/bin/python -m pip install "coal[gui] @ https://github.com/plumat-coal/COAL/releases/latest/download/coal_src.tar.gz"
  3. Start the app with ~/coal-env/bin/coal-gui and open http://127.0.0.1:7860. On a server, use the command line instead (below).

Command line and pipelines

The pip install also gives you the coal command (in ~/coal-env/bin, or $HOME\coal-env\Scripts on Windows):

coal protein.aln.fasta dna.fasta -o codon.aln.fasta
coal protein.aln.fasta dna.fasta -codontable 2 -nogap -o codon.aln.fasta
coal --help

It accepts PAL2NAL's options, and a pal2nal command that takes PAL2NAL's command line is included as a drop-in. Unlike PAL2NAL, COAL exits with a non-zero status when something is wrong, so a pipeline stops instead of carrying on with a bad alignment. For the command line alone, write coal instead of coal[gui] in the install command: it then installs nothing else.

Updating: run the same install command again; it fetches the newest release.

Check a download

Every release has a SHA256SUMS.txt file. Put it in the same folder as your download and compare.

Windows (PowerShell)

Get-FileHash .\COAL-Setup-windows-x64.exe -Algorithm SHA256

The long hex string must equal the one on the COAL-Setup-windows-x64.exe line of SHA256SUMS.txt (upper or lower case doesn't matter).

Linux

sha256sum -c --ignore-missing SHA256SUMS.txt

Each file you downloaded must say OK.

macOS

shasum -a 256 coal_src.tar.gz

Compare with the coal_src.tar.gz line of SHA256SUMS.txt.

Why COAL

PAL2NAL has done this job for twenty years. COAL does the same job, faster, and explains itself.

Checked against PAL2NAL
Tested against PAL2NAL version 14's own output: 165 checks on 38 input cases and every FASTA option. The output is byte-identical in 147 checks; the rest are inputs both tools reject or documented, deliberate differences.
Faster on real-sized data
Measured on one Windows 11 laptop, synthetic data, median of 3 runs: 100 genes of 10,000 codons took PAL2NAL 24.5 s and COAL 0.207 s (118.6×). 10,000 genes of 500 codons: 24.7 s against 0.864 s. For tiny inputs both take about 0.05 s, so there's no gain there.
Large inputs in little memory
Measured on the same laptop: half a million genes (974 MB of input) in 9.8 s with 4 processes; one process peaked at 131 MB of memory.
Tells you what's wrong
A gene that doesn't fit gets a sentence, not a cryptic line: a frameshift and roughly where, IDs that don't match, or mitochondrial genes run with the standard genetic code (with a one-click re-run). The app also writes a methods paragraph for your paper.
Your data stays on your computer
The app runs locally and works offline. Pure Python, MIT licence. AI assistants can use it too, through MCP.
