Install

Steps for Windows, macOS, Linux and the command line only. To update, run the same install again: it fetches the newest release.

Windows

  1. Download COAL-Setup-windows-x64.exe.
  2. Edge may say the file isn't commonly downloaded. Select … next to the message, then Keep, Show more and Keep anyway.
  3. Open the file. Windows shows Windows protected your PC. Select More info, check that the app is COAL-Setup-windows-x64.exe and the publisher is Unknown publisher, then select Run anyway. You can check the file's checksum first.

  4. Choose whether you want a desktop shortcut and an Open with entry for .fasta and .aln files. Both are optional. Select Install. COAL goes into %LOCALAPPDATA%\Programs\COAL.
  5. If you use Claude Desktop, keep Connect COAL to Claude Desktop ticked on the last page. Then quit Claude Desktop completely (right-click its icon by the clock, then Quit) and open it again. You can now ask Claude, for example, Use COAL to make a codon alignment from the files in C:\Users\me\Documents\genes and save it there. Claude asks before each run; your files stay on your computer.
  6. Start COAL from the Start menu. The first start can take about 10 seconds. Drop your protein alignment and DNA onto the window, or select Try an example.

If Smart App Control blocks COAL

Smart App Control on Windows 11 blocks unsigned apps. It has no Run anyway button and no way to allow a single app. You can switch it off, but on some Windows versions it can then only be switched back on by resetting or reinstalling Windows. We suggest leaving it on and installing with pip instead. In PowerShell, with Python 3.10 or newer from python.org:

py -m venv $HOME\coal-env & $HOME\coal-env\Scripts\python -m pip install "coal[gui] @ https://github.com/plumat-coal/COAL/releases/latest/download/coal_src.tar.gz" & $HOME\coal-env\Scripts\python -m coal_app

The last line starts the app. Open http://127.0.0.1:7860 in your browser. The app listens on this computer only.

To run COAL without installing it, unzip COAL-windows-x64.zip and run COAL\COAL.exe. Windows asks for the same confirmation. On a managed university or company computer, IT policy may block both.

macOS

  1. In Terminal, run python3 --version. You need 3.10 or newer. If yours is older, install the current Python from python.org.
  2. Make a virtual environment for COAL:
    python3 -m venv ~/coal-env
  3. Install COAL and its app into it:
    ~/coal-env/bin/python -m pip install "coal[gui] @ https://github.com/plumat-coal/COAL/releases/latest/download/coal_src.tar.gz"
  4. Start the app and open http://127.0.0.1:7860 in your browser. Ctrl+C in Terminal stops it.
    ~/coal-env/bin/coal-gui

Linux

  1. Run python3 --version (3.10 or newer). On Debian and Ubuntu you may also need sudo apt install python3-venv.
  2. Recent Debian, Ubuntu and Fedora refuse pip install outside a virtual environment, so make one and install COAL into it:
    python3 -m venv ~/coal-env ~/coal-env/bin/python -m pip install "coal[gui] @ https://github.com/plumat-coal/COAL/releases/latest/download/coal_src.tar.gz"
  3. Start the app with ~/coal-env/bin/coal-gui and open http://127.0.0.1:7860. On a server, use the command line.

Command line only

The pip install also puts coal and pal2nal in ~/coal-env/bin ($HOME\coal-env\Scripts on Windows). For the command line alone, write coal instead of coal[gui] in the install command. The engine has no required dependencies.

coal protein.aln.fasta dna.fasta -o codon.aln.fasta
coal protein.aln.fasta dna.fasta -codontable 2 -nogap -o codon.aln.fasta
coal --help

Check a file

Download SHA256SUMS.txt into the same folder as the file, then run the command for your system.

Windows (PowerShell)
Get-FileHash .\COAL-Setup-windows-x64.exe -Algorithm SHA256
The hash must equal the one on that file's line of SHA256SUMS.txt. Case does not matter.
Linux
sha256sum -c --ignore-missing SHA256SUMS.txt
Every file you downloaded should print OK.
macOS
shasum -a 256 coal_src.tar.gz
Compare the result with that file's line of SHA256SUMS.txt.
