Cite COAL

If you use COAL in published work, please cite the version you used. coal --version prints it.

References

Newton C, Murati K (2026). COAL: codon alignments from protein alignments, version 0.4.2. https://github.com/plumat-coal/COAL

COAL follows PAL2NAL's method, so please cite PAL2NAL too:

Suyama M, Torrents D, Bork P (2006). PAL2NAL: robust conversion of protein sequence alignments into the corresponding codon alignments. Nucleic Acids Research 34:W609–W612.

The repository's CITATION.cff holds the COAL reference in a form that reference managers can read.
